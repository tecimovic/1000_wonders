# GTFS

The MBTA publishes bulk schedule data in a General Transit Feed Specification (GTFS) feed. GTFS and [GTFS Realtime](/developers/gtfs-realtime) data describe our system and service, in an industry-standard format. To learn more, visit GTFS.org:

[Read GTFS Reference documentation](https://gtfs.org/documentation/schedule/reference/)

## MBTA GTFS Feed

[MBTA GTFS Documentation](https://github.com/mbta/gtfs-documentation/blob/master/reference/gtfs.md) provides updated specification extension information. It is intended to supplement, not replace, the GTFS.org documentation.

To get our GTFS data:

[Download MBTA GTFS files (ZIP, 10–30 MB)](https://cdn.mbta.com/MBTA_GTFS.zip)

You can also use the [V3 API](/developers/v3-api).
